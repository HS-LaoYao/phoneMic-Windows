# phoneMic · Windows 客户端

把安卓手机当成电脑麦克风，并能在说话的同时自动按住电脑上的某个键（支持组合键）。

> 配套手机端见另一个仓库 `phoneMic-Android`。

---

## 它做什么

- 电脑上打开本程序，手机 App 会自动在局域网里找到它，**不用手输 IP**
- 手机说话的瞬间，本程序把声音送进虚拟声卡 → 任何软件都能把「CABLE Output」当麦克风用
- 如果设置了联动按键（比如左 Alt），说话时本程序会**同步按住 Alt，停止时松开**
- 支持两种手机端模式：长按说话、点按常开 —— 电脑端不需要区分，自动跟随

---

## 安装

1. 把 `phoneMic-windows.zip` 解压到任意目录（绿色软件，不写注册表）
2. 双击 `PhoneMic.exe`
3. 如果下拉框提示「未检测到虚拟声卡」，点右边的**安装虚拟声卡**：
   - 驱动已随包附带（`driver\` 目录，**不需要联网**）
   - 会打开 VB-CABLE 官方安装程序，点一下 **Install Driver**
   - 会弹一次管理员授权（装驱动必须），装完**建议重启一次电脑**
4. 重启后打开本程序，输出设备选 **CABLE Input (VB-Audio Virtual Cable)**
5. 在你自己的语音输入软件里，把麦克风选成 **CABLE Output (VB-Audio Virtual Cable)**

> VB-CABLE 不会改你的默认扬声器/麦克风，只是多出两个设备，不影响现有音频。
> 驱动是 VB-Audio 官方原版，未做任何修改（许可允许原样分发）。

## 设置联动按键

1. 点「重新录制」
2. 直接在键盘上按一下要联动的键
   - 单键：按一下「左 Alt」再松手
   - 组合键：按住 `Ctrl` + 再按 `空格`，然后一起松手
3. 不想联动任何键，点「清除」（显示「（不映射）」）

**说明**：只有手机端在说话时才会按下这个键，停下来就松开。断线、关闭程序都会强制松开，不会出现「Alt 卡死」。

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机找不到电脑 | ① 两个设备在同一 WiFi 吗 ② 电脑上本程序点「开始」了吗 ③ 公司/学校网络可能开了 AP 隔离，换成手机热点试试 |
| 显示已连接但对方软件没声音 | 语音软件里麦克风要选 **CABLE Output**，不是 CABLE Input，也不是原来的麦克风 |
| 下拉框里没有 CABLE | 虚拟声卡没装好，重启一次电脑；还不行就点「安装虚拟声卡」重装 |
| 按键没反应 | 目标软件以管理员运行的话，本程序也要右键「以管理员身份运行」（Windows 的权限隔离） |
| 声音断断续续 | WiFi 信号差；本程序有 300ms 缓冲，正常不会断 |

## 彻底卸载

程序右下角托盘图标 → 右键 → **彻底卸载（含虚拟声卡）**。

它会：停止服务 → 调用 VB-CABLE 官方卸载程序 → 删除 `%APPDATA%\phoneMic` 配置
→ 提示重启一次 → 之后直接删掉程序文件夹即可，不留任何东西。

## 技术说明

| 项 | 选型 |
|---|---|
| 运行时 | .NET Framework 4.8（Win10/11 自带，**无需安装**） |
| 界面 | WinForms |
| 音频输出 | NAudio（WASAPI，播放到指定设备） |
| 体积 | exe 约 40KB，连同 NAudio 合计约 650KB |
| 通信 | UDP 47810，裸 PCM 48kHz/16bit/单声道，10ms 一帧 |

协议细节见 `docs/requirements.md` 第九节。
