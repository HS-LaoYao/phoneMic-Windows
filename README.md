# phoneMic · Windows 端 v1.0.4

把手机当电脑麦克风（和耳机）。配套手机端见 `phoneMic-Android`。

## 下载

发行版页面（安装包 + 更新日志）：

- 码云　<https://gitee.com/heishanyao_admin/phoneMic-Windows/releases>
- GitHub　<https://github.com/HS-LaoYao/phoneMic-Windows/releases>

下 `phoneMic-setup.exe`，双击安装即可（VB-CABLE 虚拟声卡驱动已随包附带）。
程序里「设置 → 关于 / 更新 → 检查更新」也能直接拉最新版。

## 三种使用模式

| 模式 | 手机说话 | 电脑自己的声音 | 手机声音去哪 |
|---|---|---|---|
| **① 只当麦克风**（默认） | 只进微信/QQ | **照常从音响出，不受任何影响** | 只进虚拟声卡，**不从音响出** |
| **② 麦克风 + 监听** | 进微信/QQ | 照常从音响出 | 同时从音响放出来（自己听得到） |
| **③ 手机当音响** | —（见下） | **全从手机出，音响不出声** | — |

模式③ 的做法：把系统「默认播放设备」临时改到虚拟声卡，音响自然就没声了，再从虚拟声卡的输出端把声音读到手机。停止或切回其它模式时，**自动恢复你原来的默认播放设备**。

> **模式③ 的限制（重要）**
> 一条虚拟线只能走一个方向。单条线时，它既要送电脑声音、又要当微信麦克风，会互相污染。
> 所以单线环境下模式③ **只做「电脑声音→手机」**，此时手机不能同时当麦克风。
> 想三者兼得，需要装 VB-Audio 的 **A+B 双线版**（官网捐款后获取个人下载链接）。程序会自动识别：
> 检测到 `CABLE-A` / `CABLE-B` 两个设备时，模式③ 自动切到双线，手机麦克风同时可用。

## 安装

双击 `phoneMic-setup.exe` → 下一步 → 完成（驱动已内置，全程离线）。

- 装完建议**重启一次**
- 重启后打开 phoneMic，进「设置」点 **设为默认麦克风**（会把「默认设备」和「默认通信设备」都改成 CABLE Output）
- 然后去微信 / QQ 里试语音

> 安装虚拟声卡后系统有可能把**默认播放设备**也指到虚拟声卡，导致放歌没声音。
> 本程序启动时会自动检测并改回真实扬声器，不需要你手动处理。

## 按键联动

设置一个键（如左 Alt），手机说话时电脑会自动按住它、停下就松开。

主界面的「测试」按钮会模拟按住 3 秒并回报结果，用来排查目标软件为什么没反应。
三种注入方式在设置里切换：虚拟键码（默认）／扫描码／消息投递。

## 设置项

| 项 | 说明 |
|---|---|
| 本机地址 | 手机自动发现，一般不用管 |
| 音频路由 | 输出设备、默认播放设备检查、监听音量、模式③静音 |
| 麦克风 | 当前默认录音设备，一键改成 CABLE Output，可一键还原 |
| 声卡自检 | 录 3 秒虚拟声卡，告诉你里面到底有没有声音 |
| 按键注入方式 | 三种任选 |
| 日志 | 出问题把这里的内容发出来 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机找不到电脑 | 同一 WiFi；程序点了「开始」；公司网络可能开了 AP 隔离 |
| 微信/QQ 听不到 | 设置里点「设为默认麦克风」；个别软件要在自己的语音设置里改 |
| 放歌没声音 | 看设置里「系统默认播放设备」那行是不是红的，点「打开声音设置」改回扬声器 |
| 按键不生效 | 先用「测试」；说话前先点一下目标软件（焦点要在它上面） |
| 声音断续 | WiFi 信号差 |

## 卸载

托盘图标右键 → **彻底卸载（含虚拟声卡）**：停服务 → 卸驱动 → 删配置 → 提示重启 → 之后删文件夹即可。

## 技术

.NET Framework 4.8（Win10/11 自带，无需装运行时）+ WinForms + NAudio，安装包约 3.2MB。
通信：UDP 47810，裸 PCM 48kHz/16bit/单声道，10ms 一帧（960B）。
