# phoneMic · Windows 端

将 Android 手机用作 Windows 电脑的麦克风与耳机，同一局域网内自动配对，无需手动输入 IP。

配套手机端：[phoneMic-Android](https://gitee.com/heishanyao_admin/phoneMic-Android) ｜
[GitHub 镜像](https://github.com/HS-LaoYao/phoneMic-Android)

## 功能

- **实时传输**：手机语音以 48kHz / 16bit 单声道 PCM 实时送入电脑，帧长 10ms
- **三种音频路由模式**：仅麦克风 / 麦克风 + 监听 / 手机当音响（详见下表）
- **按键联动**：手机按下说话键时，电脑自动按住指定按键（如语音输入快捷键），可指定目标程序
- **发送键**：手机端一键触发电脑上的回车 / Shift+回车，用于发送语音转写的文字
- **远程控制**：三种路由模式可在手机端远程切换，两端界面实时同步
- **检查更新**：内置更新检测，从码云发行版获取最新版本
- **后台运行**：可最小化至系统托盘

## 模式说明

| 模式 | 手机语音 | 电脑播放 |
|---|---|---|
| ① 仅麦克风 | 送入虚拟声卡，供其他软件采集 | 不受影响，仍从扬声器输出 |
| ② 麦克风 + 监听 | 送入虚拟声卡 | 扬声器同时播放手机语音（音量可在设置中调节） |
| ③ 手机当音响 | 送入虚拟声卡 | 全部音频改从手机输出，扬声器静音，停止后自动恢复 |

模式③在单条虚拟声卡线路下，为避免回声会暂停手机上行；安装 CABLE-A + CABLE-B 双线路后可双向同时进行。

## 使用

1. 安装本程序及附带的 VB-CABLE 驱动
2. 手机安装 phoneMic-Android 并授予麦克风权限
3. 电脑端点击「开始」，手机端会自动发现电脑并连接（状态变绿即可使用）
4. 其他软件无声音时：设置 → 「设为默认麦克风」（QQ、微信等通话类软件使用独立的"默认通信设备"，程序会一并设置）

## 常见问题

**Q：微信 / QQ 语音没有声音？**
A：设置 → 「设为默认麦克风」。该操作会同时修改"默认设备"与"默认通信设备"，并通过快照-恢复机制保证默认播放设备不受影响。

**Q：安装后音乐软件播放无声？**
A：VB-CABLE 安装时可能将默认播放设备指向虚拟声卡。本程序启动时会自动检测并恢复；也可在设置中确认"系统默认播放设备"一行是否显示为绿色正常。

**Q：按键联动在后台程序中不生效？**
A：后台消息投递（PostMessage）仅对遵循标准消息循环的程序有效。对仅在自身窗口处理键盘的程序，请将投递方式改为「切到前台再按」。

**Q：日志与崩溃信息在哪里？**
A：`%APPDATA%\phoneMic\` 目录下：`app.log` 为运行日志，`crash.log` 为异常堆栈。

## 技术说明

- 通信协议：UDP 47810，单端口承载音频与控制信令，设备通过子网广播自动发现
- 音频格式：裸 PCM 48kHz / 16bit / 单声道，10ms 一帧（960 字节，不产生 IP 分片）
- 运行环境：.NET Framework 4.8，Windows 10 / 11
- 第三方依赖：仅 [NAudio](https://github.com/naudio/NAudio)（Ms-PL 许可）
