# phoneMic · 功能需求清单（V1）

> 手机当电脑麦克风，支持「长按说话」与「点按常开」两种模式，并可联动 PC 按键。
> 本文档为双端开发的唯一依据。标注【AI建议】的是我补充的默认决策，你可以改。

---

## 一、项目概述

**一句话定位**：同一局域网下，把安卓手机变成一个「按住才说话」的电脑麦克风，并且能在说话的同一时刻帮你按住电脑上的某个键（或组合键）。

**要解决的问题**：
1. 电脑没有麦克风，或自带的不好用；
2. 现成方案（WO Mic）连上就一直录，没有「按住才说」；
3. 语音输入类软件要先按住 Alt（或别的键）才收音，手机上说话、手还得在键盘上按着，两头顾不上。

---

## 二、用户画像与场景

| 项 | 内容 |
|---|---|
| 目标用户 | 自己一个人用（非商用），一台 Win11 电脑 + 一台安卓手机，同一 WiFi |
| 典型场景 | 坐在电脑前对着手机说话，电脑上的语音输入软件开始识别 |
| 核心痛点 | 不想一直被录（隐私）；不想手一直按着键盘 |
| 使用频次 | 每天多次，单次几十秒到几分钟 |

## 三、版本规划

### V1（本次交付，MVP）
- 局域网自动发现电脑，无需手输 IP
- **长按说话**：按住按钮期间录音并发送，松手立即停（麦克风真正关闭）
- **点按常开**：点一下开始持续录音，再点一下停止
- PC 端可配置**单键或组合键**（键盘上直接录制，或选「不映射」）
- 说话时同步按下配置的键，停止时松开
- 断线自动重连；断开/退出时强制松开按键（防「Alt 卡住」）
- 双端界面简洁、体积尽量小

### V2（后续可选）
- 音量自动增益、降噪
- 手机端显示电脑端音量反馈（确认声音真的到了）
- 开机自启、手机端快捷开关（通知栏磁贴）
- 蓝牙 / USB 连接

### V3（暂不做）
- 多设备切换、多电脑
- 音频压缩（Opus），当前局域网带宽足够，不做

```
│  192.168.1.9 : 47810          [复制]      │
├────────────────────────────────────────────┤
│  输出设备                                  │
│  [ CABLE Input (VB-Audio Virtual Cable) ▾ ]│  ← 自动选中含 CABLE 的设备
├────────────────────────────────────────────┤
│  说话时同时按住的键                          │
│  [ 左 Alt            ]  [重新录制]  [清除]  │  ← 点「重新录制」后按键盘即可
├────────────────────────────────────────────┤
│  ☑ 最小化到托盘     ☑ 启动时自动开始        │
├────────────────────────────────────────────┤
│  日志：已连接 192.168.1.222 / 收到首个音频包 │
└────────────────────────────────────────────┘
```

**交互说明**
- 状态圆点：灰=未启动；琥珀=等待手机连接；绿=已连接待命；**红=正在说话（录音中）**
- 「重新录制」点击后按钮变「请按键…」，捕获到键盘按键后自动保存
- 关闭窗口 = 最小化到托盘（可在设置里改成真退出）；托盘右键有「退出」
- 「输出设备」下拉列出系统所有**播放**设备，默认选名字含 `CABLE` 的那个

**交互说明**

## 八、技术选型

| 端 | 技术 | 理由 |
|---|---|---|
| Windows | **C# / .NET Framework 4.8 + WinForms + NAudio** | Win11 自带 .NET FW 4.8，**不需要安装任何运行时**；产物 exe(~200KB)+NAudio.dll(~700KB)，合计约 1MB；NAudio 是成熟的 WASAPI 封装，播放到指定声卡最稳 |
| Android | **原生 Kotlin，不使用 AndroidX / Compose** | 只依赖系统 API，APK 预计 150–300KB；构建快、不需要额外库 |
| 通信 | **自研极简 UDP 协议** | 不再兼容 WO Mic 的私有 Opus 协议（那正是之前失败的根源）；裸 PCM 局域网毫无压力，零编解码依赖 |

## 九、协议设计（V1）

电脑监听 UDP **47810**，手机主动发。所有包第一个字节是类型。

| 类型 | 方向 | 内容 |
|---|---|---|
| `0x01` 音频 | 手机→电脑 | `[01][seq:u16][PCM 960字节]` = 963 字节，10ms 一帧 |
| `0x10` 说话开始 | 手机→电脑 | `[10]` → 电脑：按下配置的键 |
| `0x11` 说话结束 | 手机→电脑 | `[11]` → 电脑：松开键 |
| `0x12` 心跳 | 手机→电脑 | `[12][mode]` 每秒一次，mode: 0=长按 1=常开 |
| `0x20` 发现请求 | 手机→广播 | `[20]` |
| `0x21` 发现应答 | 电脑→手机 | `[21][nameLen][name utf8]`，手机据此得到电脑 IP |

- 音频帧 10ms / 960 字节，单包 963 字节，**不会有 IP 分片**
- 电脑端 2 秒收不到任何包 → 判定断线，松开所有按键
- 无压缩、无加密，纯局域网

## 十、关键技术前提（必须你确认）

**手机的声音要「变成」电脑上的麦克风，Windows 必须有一个虚拟声卡。**

这是系统结构决定的，不是实现选择 —— 任何软件（包括 WO Mic）都得这么做，区别只是用谁的驱动：
- WO Mic 用的是它自己的私有驱动 `womic.sys`，接口不公开，别的程序写不进去；
- 所以我们要用一个公开标准的虚拟声卡：**VB-CABLE**（约 2MB，免费，装一次永久可用，装完不用管）。
- 装完后：本程序把声音写进 `CABLE Input`，你的语音输入软件选 `CABLE Output` 当麦克风即可。

> 副作用（好消息）：装好这个之后，**WO Mic 可以彻底卸载**，它的驱动也一并清掉。
